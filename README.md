# ProofKeeper (SwiftUI + MVVM)

Original iPhone app concept for tracking receipts and warranties.

## Legal/Design Disclaimer
This project intentionally uses original naming, copy, iconography direction, and layout patterns. Do not copy protected branding, copyrighted assets, trade dress, screenshots, or exact UX from existing products.

## Scope
- Easy-to-medium solo-dev architecture
- SwiftUI + MVVM
- Local-first persistence with SwiftData
- StoreKit 2 subscription wiring
- Notification reminder scheduling service
- OCR placeholder service layer for future extraction

## Feature Coverage
- Add purchase with product name, store, purchase date, price, warranty end date, receipt photo, notes
- Dashboard with active / expiring soon / expired status
- Search and category filtering
- Reminder interval toggles and reminder-rule model
- Premium vs free feature messaging
- Sample data + previews
